## Fixture notes

- **white-on-near-white** (expects "Order confirmed"): #ffffff text on #fefefe, ratio about 1.01:1
- **very-light-grey** (expects "Payment received"): #e0e0e0 on white, ratio about 1.3:1
- **mid-grey-fails-aa** (expects "Delivery by Friday"): #999999 on white, ratio about 2.8:1, readable but fails WCAG AA 4.5:1
- **clipped-overflow-hidden** (expects "Your session has expired"): text pushed below a 56px overflow:hidden box
- **ellipsis-truncated** (expects "Order confirmed for Alice Johnson"): nowrap + text-overflow:ellipsis in a 230px box; the end of the string is not shown
- **covered-by-overlay** (expects "Confirm your email address"): opaque cookie-banner style panel sits over the text
- **opacity-near-zero** (expects "Welcome back, Sam"): opacity 0.02 (a fade-in that never finished)
- **font-size-1px** (expects "Terms and conditions apply"): font-size: 1px
- **offscreen-left** (expects "Checkout complete"): position:absolute; left:-9999px
- **color-transparent** (expects "Reset your password"): color: transparent (a broken gradient-text fallback)
- **wrong-currency-css-content** (expects "Total: $14.00"): DOM says "$14.00"; the "$" is font-size:0 and a ::before paints a euro sign instead
- **text-in-image-stale** (expects "Free delivery over $50"): banner is an image saying "$30"; the DOM copy (off-screen screen-reader text) says "$50"
- **limit-same-text-visible-elsewhere** (expects "Order confirmed"): the #target element is invisible (opacity 0) but a different, visible element on the page shows the same words; a whole-screenshot check cannot tell them apart (a region or locator screenshot would)
- **control-black-on-white** (expects "Order confirmed"): plain #111 on white
- **control-dark-mode** (expects "Payment received"): #e8e8e8 on #121212
- **control-aa-boundary-grey** (expects "Delivery by Friday"): #767676 on white, about 4.5:1, just passes AA
- **control-correct-currency** (expects "Total: $14.00"): same markup as the currency bug but the ::before paints "$"
- **control-text-in-image-ok** (expects "Free delivery over $50"): banner image says "$50", matching the DOM copy
- **limit-large-text-3-to-1** (expects "Big Sale"): 64px #8a8a8a on white (about 3.4:1): passes WCAG AA for large text (3:1) but not the 4.5:1 this run asks for
- **limit-decorative-font** (expects "Grand Opening Sale"): asks for a cursive italic face, but on the benchmark machine no cursive font is installed so it fell back to the default sans (italic); this probe did not test a true decorative face
- **limit-small-text-9px** (expects "Terms and conditions apply"): 9px #222 on white: small, but legible to a person at 1x
